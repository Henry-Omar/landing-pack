# 行前打包 & 材料清单 · Pre-departure Packing & Docs (中文)

> 适用于赴英 / 美 / 澳 / 加 / 日 的中国留学生。按学校专属清单（APP 内）勾选后再对照本表。

## 一、必须随身带（别托运）
- [ ] 护照（有效期 ≥ 6 个月）+ 签证 / BRP / 在留卡
- [ ] 录取信 / CAS / I-20 / CoE / LOA（纸质 + 电子版）
- [ ] 机票行程单、住宿确认信
- [ ] 护照尺寸照片（白底，多张）
- [ ] 体检 / 疫苗 / 肺结核(TB)报告
- [ ] 资金证明、奖学金 / GIC 凭证
- [ ] 信用卡（美元/本地币种，开通境外消费）
- [ ] 少量当地现金（落地打车 / 吃饭）

## 二、证件 & 复印件（分开放）
- [ ] 护照首页 + 签证页复印件 ×2
- [ ] 身份证复印件（国内备用）
- [ ] 学校联系方式、接机人电话（写纸上）

## 三、生活用品
- [ ] 转换插头 + 插线板（英标/美标/澳标/日标按国别）
- [ ] 常用药品（退烧、肠胃、过敏；注意各国违禁成分）
- [ ] 眼镜 / 隐形眼镜 + 处方
- [ ] 四季衣物（按目的城市气候；北方冬季备厚衣）
- [ ] 手机 + 充电器（落地前开通国际漫游）

## 四、到校 7 天内
- [ ] 领取 BRP / 在留卡 / 学生证
- [ ] 银行开户（带护照 + 签证 + 住址证明）
- [ ] 办理本地手机卡 / 学生优惠
- [ ] 校内注册、选课、办交通卡
- [ ] 向家人报平安

> 更多：在 APP 内选择你的学校，查看「到校贴士」与专属清单。
